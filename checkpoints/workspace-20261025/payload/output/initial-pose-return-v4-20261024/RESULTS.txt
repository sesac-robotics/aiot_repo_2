시작 자세 학습과 AI 복귀/단계 완료 경로 — 2026-10-24

확인한 구현 문제: 푸시업과 숄더 프레스는 끝부분 각도 특징을 학습했으며, 스쿼트에서 보강한 시작 상태 학습/복귀 사건 확인 경로가 일관되게 확장되어 있지 않았다. YTW에는 연속 단계 완료를 확인하는 학습 경로가 빠져 있었다. 이를 AI가 복귀 자세를 본질적으로 학습할 수 없기 때문이라고 설명하면 안 된다.

이번 구현: 운동별 시작/복귀 상태와 동작 중 상태를 프레임에서 별도 라벨링해 지도 학습했다. 첫 장면을 무조건 정상이라고 가정하지 않는다. 동작 중 굽힌 자세는 복귀 전 상태이지 오류 동작/0점이 아니다. AI 상태 인식 이후 시작 확인→자세 이탈→복귀 재확인 순서를 검사한다. 준비 자세로 서 있기만 하면 반복이 늘지 않는다. 누락/영상 잘림/사용자 종료는 실패 점수로 만들지 않는다.

운동별 목표:
스쿼트: 서 있는 상태와 초기 골반/어깨 높이에 대한 복귀. 비교 특징에 높이 기준점을 보존했다.
푸시업: 팔을 편 복귀 항목의 상태. 무릎 접지/몸통 등의 전체 품질과 구분한다.
숄더 프레스: 어깨 높이의 준비 자세→들기→준비 자세 복귀. 이번 상태 학습 구도는 정면·앉은 자세다.
YTW: 실제 팀 영상처럼 Y→T→W를 이어서 수행하는 순서를 학습했다. 영상에 없는 매회 팔 내림을 강제하지 않는다. 이번 단계 모델은 직립형에 한정한다.
플랭크: 반복 복귀 대신 지지 자세 유지/변화를 확인한다. 처음부터 엉덩이가 높거나 처진 자세를 정상 시작으로 학습하지 않는다.

자료: 기존 팀 Train 영상만에서 추가 상태 라벨을 만들었다. 기존 동작 점수 정답, 사람별 정상·오류 Train/Test 원본 배정은 변경하지 않았다. 이 별도 상태 실험이 기존 QEVD/REHAB/해군/AI-Hub 등을 함께 학습한 점수 모델을 대체하지 않는다.
검토 원본 21개, 새 상태/단계 앵커 210개, 실제 관측 가능한 학습 프레임 205개, 관측 보류 5개다. V47은 접지가 불확실하므로 복귀 전/오류 상태로 강제하지 않고 최종 상태 학습에서 제외했다. P02/P04의 정상 지지 영상과 명확한 엉덩이 상승/처짐 영상을 함께 추가했다. 사람 자체를 정상/오류로 라벨링하지 않았다. 사람별 운동·유형의 빈칸은 기존 고정 분할에 따라 여전히 존재한다.

모델: 초기/복귀 상태를 학습하는 분류기와 Y/T/W 단계 분류기를 새로 학습했다. 다른 사람을 뺀 그룹 교차검증으로 후보를 정했다. 같은 사람의 이웃 프레임을 임의 Train/Test로 나누지 않았다. 기준 프레임 자체는 상태 검증 분모에서 제외했다. 측면 푸시업/플랭크는 실제 보이는 관절 사슬을 사용하며, 가려진 반대쪽 관절을 채우지 않는다. 스쿼트도 관찰되는 다리 사슬을 사용한다.

연속 영상 검증: 평가 대상 사람을 학습에서 제외한 모델로 같은 서비스 API를 호출했다. 검토된 첫 최대11.8초 범위의 상태/복귀 사건을 기록했다. 여기의 사건 수는 수작업 정답과 전부 대조한 반복 수 정확도가 아니다. 첫 장면이 이미 움직임 중이거나 시작 상태의 관측이 부족하면 첫 반복은 확인하지 못할 수 있다. 짧은 구간에서 시작 상태를 잘못 가정해 반복을 만들어 내지 않았다.

플랭크 초기 후보는 개발 기준 미달로 서비스 분석 경로에서 사용을 막았다. 준비 상태가 아닌 자세25개 중6개를 준비 상태로 잘못 인식했다. 준비 상태를 인식하는 AI 자체를 미지원으로 고정한 것이 아니라, 학습한 후보가 기준을 통과하지 못한 상태다.
정지 프레임의 소프트 확률0.8을 모든 모델에 같은 신뢰도로 간주하면 연속 시작 확인을 놓치는 문제도 확인했다. 학습된 상태 클래스 판단을 연속 관측으로 확인하고 소프트 확률은 별도 근거로 남기도록 고쳤다. 첫 프레임·마지막 프레임이라는 이유로 상태 정답을 만들지 않는다.

서비스 코드: app/scoring/initial_pose_return.py와 ScoringEngine.analyze_initial_return에 새 경로를 연결했다. 학습한 로컬 객체를 전달해 실행할 수 있고, 미학습 구도/프로토콜·개발 기준 미달 후보는 보류한다. 기존 score()의 0/1/2 등급이나 라이브 모델 파일을 자동 교체하지 않았다. 새 상태/순서 근거를 0/1/2점 판정이 완성되었다는 뜻으로 혼동하지 않도록 grade=None을 명시했다.

남은 일: 복귀 실패가 있는 완결 시도에서 부분 복귀/미복귀의 점수 등급 검증, 시작 관측이 짧거나 누락된 영상, 다른 촬영자/구도에서의 일반화, 플랭크 과잉 정상 인식을 보강해야 한다. 기존 점수 모델과 새 상태 근거를 최종 점수에 통합해 실시간 전체 경로까지 검증한 상태는 아니다. 별도 최종 Test는 열지 않았다.

검증: 상태/복귀/순서/높이 기준 보존 회귀20개와 기존 서비스41개, 총61개 통과. 현재 특징 함수와 저장된 학습 특징값도 전체 프레임에서 동일한 것을 확인했다. 모델·라벨·원본 분할 해시는 verification.json에 기록했다.
