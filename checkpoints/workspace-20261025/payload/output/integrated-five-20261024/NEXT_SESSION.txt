현재 판정
- 24개 항목 모델 중 3개만 내부 추가 검증 조건을 통과했다. 이것은 서비스 채택이나 독립 성능 인증이 아니다.
- 추가 검증 후보: 정면 푸시업 하강, 측면 스쿼트 무릎·발 복합, 서서 YTW의 T 단계.
- 기존 서비스 모델과 복귀 전용 기존 모델은 교체하지 않았다. 새 후보가 모든 항목을 개선했다고 주장하면 안 된다.
- 새 복귀 트리는 고정 개발 검증에서 부분 복귀 6개 중 1개만 검출했다. 신경망은 부분 복귀를 검출했지만 정상의 절반을 오탐했다. 에포크 수만 늘리면 해결된다고 볼 수 없다.
- 심한 복귀 실패 0등급, 프레스 하단 미복귀·몸통 오류, 플랭크 지지 중단 등은 독립 사람의 충분한 오류 사례가 더 필요하다. 한 출처의 반복 창을 늘리는 것만으로 해결되지 않는다.
- AI-Hub는 제공된 2D 관절·자세 조건 학습이다. 원시 이미지 전체 또는 MediaPipe 자체를 재학습한 것이 아니다. 엄지 방향은 현재 입력으로 관찰할 수 없어 제외.

다음 우선순위
1. score-training.json의 오류 검출 실패와 정상 오탐 사례를 source_id/사람 그룹별로 다시 영상과 대조한다. 라벨 의미·기준·촬영 방향이 일치하는지 확인한다.
2. 아직 정상만 있는 항목은 기존 전체 데이터에서 해당 오류가 명확한 실제 장면을 찾아 독립적으로 라벨링한다. 복귀 실패를 얕은 스쿼트나 잘린 영상으로 대신하지 않는다.
3. AI-Hub 원시 이미지와 Training 라벨을 연결하는 경우에는 이미지·사람 분할을 먼저 검증하고, 검증 자료를 학습에 옮기지 않는다.
4. 새 사람·새 촬영에서 고정된 모델을 시험한 뒤 적용한다. 기존 개발 검증을 반복해서 보고도 새 최종 시험이라고 부르지 않는다.
