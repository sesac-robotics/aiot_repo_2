비교 모델과 한계

AI 비교 전은 직전 기하 특징 후보의 학습 방법을 같은 그룹에서 다시 학습한 결과입니다. 실행 중 모델을 직접 측정한 수치가 아닙니다. Rule Base는 기존 상대 무릎 간격·몸통 변화 특징의 임계값을 매 학습 그룹에서 다시 맞췄습니다. 기존 후보와 원본은 그대로 보관했습니다.

이전에 사용한 개발 자료를 재사용했습니다. 독립 최종 시험 성능으로 주장하지 않습니다. 수행자 ID 분리는 제공된 데이터셋 ID 기준입니다.

새 오류 라벨을 억지로 만들지 않았습니다

4,150개 목록에서 제공자 오류 태그를 우선한 96개와 자동 선별 후보 중 80개를 확인했습니다. 합계 176개는 시간순 표본 검토이며 연속 영상 전체 검토·전문가 확정은 아닙니다. 4개 의심 원본은 각각 24개 프레임으로 추가 확인했습니다.

  • 복귀: 영상이 하강 중 끝나는 것을 복귀 실패로 처리하지 않았습니다.
  • 무릎: 좁은 스탠스·무릎 전방 이동·투영 변화만으로 무릎 안쪽 붕괴를 확정하지 않았습니다.
  • 몸통: 제공자 ‘등이 곧지 않음’ 표시는 전후 숙임을 포함합니다. 이를 현재의 정면 좌우 안정 오류 라벨로 바꾸지 않았습니다.

새 오류 라벨 확보와 그 라벨을 추가한 재학습은 아직 이루지 못했습니다. 이번 재학습은 기존 오류 사례의 가중치를 조정한 실험입니다. 검토한 176개도 정상 학습 정답으로 채택하지 않았으며 추가 판정 대상으로 남겼습니다.
