5종 운동 시작/복귀 AI 보강 — 개발 체크포인트 2026-10-24

이번에 수행한 일
1. 기존 팀 상태 라벨 210개를 그대로 유지하고, 기존 미국 해군 및 다른 촬영자 자료에서 직접 다시 확인한 플랭크 정상/처짐 32개를 추가했다. 총 라벨 242개 중 실제 관측 가능한 237개를 학습했다. 가림이 불확실한 V47은 강제로 정상/오류에 넣지 않았다. 상태 0은 준비 자세가 아님을 뜻하며 운동 점수 0이 아니다.
2. 촬영자 전체를 제외하는 개발 검증을 유지했다. 같은 촬영자의 인접 프레임을 임의로 Train/Test로 나누지 않았다. 정상/오류가 한 사람의 신원에 붙지 않도록 두 외부 촬영자 모두 정상과 처짐 상태를 함께 사용했다.
3. 프레임 수치만으로 채택하면 잘못된 자세를 연속 정상 시작으로 잡는 문제가 남았다. 직접 확인한 연속 구간 10개를 동결하고, 사람 제외 개발 검증에서 정상 시작 오인과 놓침을 함께 비교해 플랭크 후보를 선택했다. 이 구간은 모델 선택용 개발 자료이며 독립 최종 Test가 아니다.

같은 기존 팀 플랭크 상태 프레임 비교: 오류 자세의 정상 오인 6/25 → 1/25. 정상 상태 놓침 0/12.
외부 자료까지 포함한 플랭크 프레임 개발 검증: 정상 준비 놓침 2/26, 준비 자세가 아닌 프레임의 정상 오인 1/41.
연속 구간 개발 검증: 잘못된 자세 6구간에서 정상 시작 오인 0, 정상 자세 4구간에서 시작 놓침 0. 이후 더 긴 원본 서비스 경로에서도 기록을 확인했다. 이 수치를 독립 Test 정확도 또는 5종 동작 점수 정확도로 해석하지 않는다.

점수 연결
ScoringEngine.score_with_initial_return 실험 API를 추가했다. 같은 구간에 기존 항목/Rule과 새 시작/복귀 상태 AI를 호출한다. 복귀 사건을 찾았다고 2점을 만들지 않는다. 정상/오류의 점수 학습, 개발 기준 통과, 정확한 특징 버전 확인이 모두 필요하다. 미학습 0점 외삽, 사용자 종료/누락을 실패로 처리하기, 여러 반복을 하나의 복귀 점수로 처리하기를 막았다. 스쿼트 무릎 폄 점수를 서기 높이 복귀로 바꿔 부르지 않는다. 기존 점수 특징과 새 목표가 다르면 보류한다.
실제 학습 모델 객체와 검토된 Train 구간으로 5종 서비스 호출을 확인했다. 현재 복귀 등급 후보는 기준 미달/지원 부족 또는 특징 목표 불일치가 있어 최종 복귀 점수로 채택되지 않는다. 테스트의 예시 점수 모델 통과가 실제 모델 성능 검증을 대신하지 않는다.

복귀 실패 데이터 확인
기존 숄더 프레스 측면 오류 시범 8개를 시간순 12장씩 추가 선별 검토했다. 영상 전체의 bad 태그를 복귀 실패 정답으로 복사하지 않았다. 일부 상단 범위/몸통 문제는 보이나, 이 표본 검토만으로 완결된 복귀 실패 점수를 확정할 수 없어 추가 실패 라벨 0개로 기록했다. 더 촘촘한 반복 구간 검토가 필요하다.
현재 혼합 점수 학습의 숄더 프레스 정면 lower_return은 정상 104개뿐이다. 푸시업/스쿼트 일부 복귀 항목에 부분 복귀 1점 자료가 있지만, 확인한 복귀 점수 head 전체에서 심한 미복귀 0점의 관측 학습 사례는 없다. 정상 시작 상태 학습과 0/1/2 실패 정도 학습은 별도다.

분할과 기존 자료
기존 원본별 Train/Test 배정, 기존 혼합 점수 모델과 Test 입력 해시를 유지했다. 정확한 사람별 정상/오류 80/20은 달성된 상태가 아니며, 사람×운동×정상/오류×Train/Test 80칸 중 37칸이 비어 있다. 같은 원본을 양쪽에 넣거나 기존 Test를 Train으로 옮겨 빈칸을 메우지 않았다. 세부 인원별 수치는 return-grade-and-split-audit.json에 기록했다.
이 상태 후보는 기존 QEVD, REHAB, 미국 해군, AI-Hub 전이 특징 등을 사용한 혼합 점수 모델을 대체하지 않는다. 기존 Test는 과거 노출된 진단 자료이며 별도 미사용 최종 Test는 열지 않았다.

검증
상태/순서 회귀 20개 + 서비스/점수 연결 회귀 55개 = 75개 통과. 실제 서비스 통합 5구간, 연속 서비스 25원본 경로를 검증했다. 학습 원본·라벨·모델·구현 해시 및 사람 제외 학습 ID를 검증했다.

남은 필수 작업
실제 부분 복귀/미복귀가 확정되는 완결 구간 확보와 등급 라벨 검증, 해당 등급 모델 재학습, 새 상태 기반 특징과 점수 특징의 버전 일치 검증, 동일 고정 진단 Test의 AI/Rule 비교 재실행, 시작 관측 부족 및 촬영 구도 확대, 라이브 촬영/UI 전체 경로 검증이 남았다. 현재 라이브 모델 교체나 5종 전체 평가 완료를 선언하지 않는다.
