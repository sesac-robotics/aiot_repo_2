촬영 및 분석
  단일 인물, 수평으로 고정한 측면 카메라, 전신이 보이는 구도입니다.
  일반 스쿼트 또는 일반 푸시업을 선택합니다.
  기립 또는 팔을 편 자세를 잠시 유지하고 반복을 시작합니다.
  120초ㆍ300MB 이하 영상을 선택해 분석합니다.
  끝까지 내려갔다 다시 펴지 않은 반복과 관절 누락 구간은 집계에서
  제외될 수 있습니다. 정면 구도 자동 검사는 완벽하지 않습니다.

라벨 초안 검토
  자동 점수는 규칙 초안이며 전문가 정답이 아닙니다.
  반복 보기 버튼으로 영상과 관절을 확인합니다.
  실명 대신 P001 같은 참여자 코드를 입력합니다.
  같은 인물의 다른 영상에는 같은 코드를 사용합니다.
  측면 촬영 여부를 확인하고 초안 승인 / 수정 점수 저장 / 학습 제외를
  선택합니다. 승인 행도 전문가 검증 완료라고 표시하지 않습니다.
  전체 라벨 CSV: 미검토ㆍ제외 행을 포함하고 상태를 구분합니다.
  검토 완료 CSV: 승인ㆍ수정한 행만 포함합니다.
  검토 점수는 원래 자동 점수를 덮어쓰지 않으며 변경 이력이 남습니다.

출력 파일 (jobs/<작업ID>/)
  input.video: 업로드한 원본. 직접 분석한 보관 영상은 복사하지 않습니다.
  overlay.mp4: 관절 표시 영상. 최대 10fps, 소리 없음.
  landmarks.npz: 시각(초), 정규화 영상 x/y 관절, visibility 배열.
                누락 좌표는 NaN입니다. 보간된 정답 좌표가 아닙니다.
  measurements.json: 시각별 투영 각도(도) 또는 측정 불가(null).
  result.json: 미검토 규칙 점수, 영상 해시, 배점ㆍ경계값 버전.
  review.json: 사람이 저장한 검토와 변경 이력. 검토 없으면 생성되지 않음.
  영상과 결과는 외부로 전송하지 않으며 자동 삭제하지 않습니다.

검증 범위
  보관된 측면 스쿼트ㆍ푸시업 예제에서 각 1회 검출과 파일 생성 확인.
  정면 스쿼트 예제는 측정 불가 처리 확인.
  합성 관절 각도의 반복 경계ㆍ누락ㆍ미완료 검사 통과.
  검토 초안 분리ㆍ잘못된 점수 거절ㆍ수정 충돌ㆍCSV 제외 검사 통과.
  일반적인 정확도, 임상적 타당성, 다양한 사람에 대한 성능은 미검증.

향후 학습
  실제 촬영ㆍ검토 자료가 쌓이면 관절 시퀀스 → 점수의 별도 모델을 학습.
  MediaPipe Heavy는 관절 추출용으로 사용하며 재학습하지 않습니다.
  참여자별로 학습ㆍ검증ㆍ시험을 분리합니다.
  규칙으로만 만든 라벨은 주로 규칙을 모방하는 학습 목표가 됩니다.
  점수의 타당성은 독립적인 사람 채점 자료로 따로 검증해야 합니다.
  현재 단계에서는 별도 점수 예측 모델을 학습하지 않았습니다.
