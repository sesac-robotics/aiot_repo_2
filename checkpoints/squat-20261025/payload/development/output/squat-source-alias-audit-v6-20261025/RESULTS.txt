스쿼트 원본 중복·분할 감사 / v6

이 단계는 스쿼트만 대상으로 한 원본 무결성 감사다. 숄더 프레스 이미지나 라벨을 스쿼트 학습에 사용하지 않았다. 실제 fit 0, 기존 모델 교체 0. 화면·설명 혼선은 성능 증거로 사용하지 않는다.
스쿼트 MultiView 150개 파일을 바이트 해시로 확인한 결과 고유 원본은 145개이며 중복 5쌍이다. 제공자 good/bad 폴더를 동시에 가진 중복 3쌍이 있어 제공자 태그를 점수 정답으로 복사해서는 안 된다.
005 bad side와 006 bad side는 완전히 같은 바이트다. 이전 15개 Train 측면 파일 검토는 고유 영상 14개로 정정한다. 별도 사람 15명의 독립 자료라고 해석하지 않는다. 005 부분복귀 초안은 새 독립 오류 사례가 아니며 학습 보류를 유지한다.
026 bad side와 015 good side도 동일 바이트이며 기존 사람 배정은 Train/validation으로 다르다. 이 원본은 새 Train 학습에서 제외하도록 격리 목록과 별도 검사를 추가했다. 기존 배정을 옮기지 않았다. 현재 적격 Train 입력에는 이 해시가 없고 validation 입력에만 있으므로 현재 학습의 해당 누출은 확인되지 않았다.
현재 사용 중인 후보의 Train/Test 원본 해시 중복 0, 스쿼트 후보의 바깥/안쪽 그룹검증 및 최종 앙상블 학습/보류 원본 중복 0을 확인했다. 기존 26개 산출물 해시, 팀 라벨과 분할 정책 해시가 일치한다. 동일 Test 51행/163항목 결과를 보존했다. 신규 원본 가드 기능검사 6개 통과.
성능은 기존 개발 AI 5/6·정상오판 0/13, 같은 입력 Rule 1/6·0/13 그대로다. 이 감사로 정확도가 추가 상승했다고 주장하지 않는다. 반복 노출 1명 개발 자료이고 스쿼트 복귀 진단 Test는 정상6/오류0이므로 독립 오류 검출률은 아직 미검증이다.
이번에 추가 확정한 실제 오류 라벨 0. 팀 사람별 정상·오류 배정 보존, 기존 37빈칸 유지로 정확80/20 미달. 최종 Test 영상 열람/실서비스 변경 없음.
다음 작업: 스쿼트 원본에서 초기 기립과 완결된 복귀가 확인되는 오류 구간을 계속 검토한다. 새 자료는 원본 중복 가드와 기존 split_guard를 함께 통과시킨 뒤에만 별도 후보 학습에 사용한다. 남은 r09는 정상 r05와 특징이 겹치므로 개발 정답에 맞춘 문턱 변경이나 강제 라벨 변경을 하지 않는다.
