현재 판단
개발 상태 bundle의 state_gate_passed는 프레임 상태에 관한 개발 근거다. 영상이 없는 저장497표본 및 학습에 쓴 V37/V39/V41/V43 재생은 연속 횟수 정답이나 미학습 사람 검증을 대신하지 않는다. 현재 라이브 factory 미지원/개발 bundle 미활성화 결정을 유지한다.

검증 자료와 분할
- 평가 대상은 upright_Y_T_W_v1 프로토콜이다. 기존 hinged YTW나 단순 팔 벌리기 영상을 같은 운동 순서 정답으로 쓰지 않는다.
- 기존 source/사람별 정상·오류 Train/Test 배정 및 미사용 최종 Test를 보존한다. 초기 학습에 쓴 네 사람의 다른 인접 프레임은 미학습 사람 검증이 아니다.
- 모델과 후보 수치가 고정된 뒤, 해당 상태 모델 학습에 쓰지 않은 최소2명의 영상동반 연속 개발 자료를 확보한다. 초기 비교 최소량 제안은 정상 완료10회 이상과 비완료/대기/순서오류/가림/시간누락/중간종료 음성 구간20개 이상이다. 사람·유형별 결과도 분리한다. 작은 개발 표본의 통과는 독립 최종 신뢰성 보장이 아니다.
- 새로운 영상 확보 없이 당장 가능한 검증은 기존 Train 사람을 통째로 제외해 상태 모델을 다시 학습한 뒤 연속 원본을 재생하는 개발 실험이다. 각 사람의 영상으로 시작·Y/T/W 유지·완료/취소·가림을 시간순 라벨링한다. 이는 현재 전체학습 bundle의 독립 평가가 아니라 사람 제외 개발 실험으로 보고한다. 테스트 원본을 학습으로 옮기지 않는다.

미리 동결할 공학 게이트 제안
- 모델/특징/전처리 해시를 고정하고 현재 실제10Hz 시간축, 경계2%, 관측률80% 계약을 동일하게 적용한다. 누락 슬롯은 분모에서 지우지 않는다.
- 고정된 후보에 대해 완료 시도 검출률90% 이상, 비완료/대기에서 허위 완료 비율5% 이하를 개발 목표로 둔다. 분모는 사전에 라벨링한 시도/음성 구간이며 무수히 많은 휴식 프레임으로 희석하지 않는다.
- 시간순 영상 정답의 시작·단계·종료 경계에서 90% 이상이 ±2슬롯(0.2초) 이내인지를 별도 비교한다. 주석 자체가 불확실한 경계는 억지 정답으로 넣지 않는다. 실제 영상 관측 빈도에 따라 허용 오차를 먼저 확정할 수 있지만, 결과를 본 뒤 문턱을 바꾸지 않는다.
- 정상·오류/음성·사람·구도별 누락, 허위 완료, 순서 혼동, 관측 보류를 함께 보고한다. 다섯 연속 슬롯/30초/누락 제한 등의 후보 수치를 개발 평가 결과에 맞춰 계속 조정했다면 새 고정 개발 자료로 다시 평가한다.

자동 구간의 점수 승인 계약
- 자동 auto_phase_windows는 수동 phase_windows로 이름만 바꾸어 넘기지 않는다. 자동 경계 검증용 별도 버전 계약을 제안하고 검출기/점수기 양쪽이 그 버전과 관측·프로토콜 조건을 확인해야 한다.
- 자동 경계가 검증돼도 Y 도달/전경 투영 승인과 항목별 등급 학습 지원은 별개다. 유효한 자동 회차라는 이유만으로 complete/projection 승인을 만들거나 총점을 채우지 않는다. 미관측·단일 정상등급·미학습0점은 계속 표시/보류한다.
- AI와 Rule Base는 동일 dense PoseSequence와 동일 자동 구간을 사용한다. Y/T/W 시간창을 수동 정답으로 바꿔 AI만 유리하게 평가하지 않는다.

활성화 순서
1. YTW 담당: 기존 승인 모델을 변경하지 않는 범위에서 사람 제외 연속 재생 실험과 자동 구간 계약 제안을 독립 경로로 준비한다. 기존 Train 재생을 독립 정확도로 보고하지 않는다.
2. 모델 담당: 상태 모델 사람 제외 학습·라벨/원본/해시 감사와 미학습 연속 자료 게이트 검토. 공통 scoring 변경이 필요하면 독립 패치를 제안하고 원본 파일 동시 수정을 피한다.
3. 통합 담당: 위 조건과 현재 제품 지원 범위를 확인한 뒤 명시적인 개발용 활성화 경로를 검토한다. 서비스 기본값으로 조용히 활성화하지 않는다. 실제 카메라/수집은 새 사용자 준비·시작 지시 후 통합 담당만 수행한다.
4. 최종 통합은 실제 영상 정답 비교, 회귀 검증 및 항목별 지원 상태를 함께 확인한다. 준비 상태 검출과 0/1/2 운동 심각도 평가를 구분한다.
