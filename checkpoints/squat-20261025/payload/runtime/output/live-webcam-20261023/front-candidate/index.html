하강 범위(30) + 화면 복귀 높이(20) + 좌우 몸통 안정(20) = 정면 관측 점수 /70. 측면이 필요한 무릎·발(30)은 포함하지 않으며 /100으로 환산하지 않는다.

AI 보조 합계 = 새로 학습한 AI 하강 추정 + 복귀·몸통 규칙. 규칙 합계 = 학습 자료로 보정한 하강 규칙 + 복귀·몸통 규칙. 순수 AI 총점이라고 표시하지 않는다.

실제로 학습·보강한 내용

  • 기존 REHAB 동기화 자료의 측면 직접 시각 라벨을 교사 신호로, 정면 관절만 입력하는 ExtraTrees 회귀 후보를 학습했다.
  • 학습 14구간 / 3명. 0·1·2등급 수: {'0': 2, '1': 8, '2': 4}. 기존 train/validation 사람 구분을 유지했다.
  • 규칙은 학습 구간의 골반 이동량/몸통 길이에서 두 경계를 탐색해 독립 보정했다. AI 출력을 규칙 정답으로 쓰지 않았다.
  • 복귀는 처음·끝 골반 높이 차/몸통 길이 ≤0.08이면 2, ≤0.20이면 1, 그 외 0의 실험 규칙이다. 정확한 무릎 신전이 아니다. 몸통은 기존 8/15도 경계를 유지했다.
  • 관측 80% 기준을 유지한다. 몸통과 한쪽 이상 무릎이 필요하고, 한 무릎만 보일 때 관측된 높이만 사용한다. 양 무릎 대칭이나 발 정렬을 추정해 채우지 않는다.

기존 검증 자료에서의 비교

학습에 넣지 않은 기존 개발 검증 7구간 / 1명. 하강 0~2등급 평균 절대 오차: 기존 AI 0.847 → 후보 AI 0.261. 후보 규칙 0.286; 기존 정면 하강 규칙은 경계가 없어 0/7구간만 판정.

이는 재사용된 개발 검증 결과다. 사람 1명, 2등급 검증 사례 0건이며, 독립 최종 시험·정확도 확정 결과가 아니다. 복귀·몸통 오류 사례가 부족하므로 해당 규칙의 오류 구분 성능은 검증하지 못했다. 라벨은 전문가 검증 전 시각 초안이며 기존 데이터의 GPU 추출과 USB CPU 환경의 차이가 있다.
