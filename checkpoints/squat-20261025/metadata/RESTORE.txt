manifest.json은 원본 상대 경로/크기/SHA256과 현재 로드 모델·검출 지문을 기록한다. verification.json의 archive_sha256으로 압축파일을 확인한다.
복원은 별도 빈 폴더에서 먼저 압축을 풀고 각 파일을 manifest와 대조한다. 현 작업 폴더에 일괄 덮어쓰지 않는다. 현재 경로 /home/jayden/SeSACPAI-Mid 를 코드가 참조하므로 다른 경로 복원 시 runtime_snapshot.SOURCE/server.ROOT/일부 모델 참조 경로를 명시적으로 바꿔 검증해야 한다. 이 보존으로 카메라/운동은 자동 시작하지 않는다.
검증된 런타임 의존성은 runtime-requirements.txt, 코드/모델/전체 저장 세션과 최종 결과는 압축파일에 포함한다. Python 가상환경 자체와 원본 학습 영상 전부는 포함하지 않았다.
Git에 남길 대상: 실행 코드·테스트·환경명세·모델/분할 해시·복원 문서·최종 검증 보고서. 모델과 원시 테스트자료는 별도 버전 보관 또는 LFS 등으로 명시적 포함하고 일반 .gitignore에 의해 빠지지 않았는지 확인한다. 현루트는 Git 저장소가 아니므로 기존 team-posture-scoring에 커밋해도 output 코드가 자동 포함되지 않는다. 다른 담당의 미커밋 학습 변경과 섞어 전체 git add 하지 않는다.
최신 실테스트는 관절기록7회/점수재현 및 산술 일치. 영상 없는 정면 추정의 한계와 긴 누락/일부 얕은 시도 미해결도 보존한다. 추가 운동 개선 때는 이 기준 보존본을 고정하고 공통변경에 스쿼트 회귀를 수행한다.
