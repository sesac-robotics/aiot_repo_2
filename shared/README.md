# 공통 전송 어댑터

JPEGFrameParser는 표준 라이브러리만 사용하는 상태 객체입니다. HTTP 청크가 JPEG 표식 중간에서 나뉘거나 multipart 헤더가 섞여 들어와도 프레임을 조립합니다. 최대 8 MiB를 넘는 미완성 입력은 버리고 다음 표식으로 재동기화합니다. 객체 하나를 연결 하나에 사용합니다.

GUI와 백엔드가 이 파서를 공유하지만 이미지 디코딩·인증·네트워크 연결을 공유하지는 않습니다. FF D8 / FF D9 표식이 있다고 유효한 영상으로 확정할 수 없으므로 GUI OpenCV 디코더가 추가 검사를 합니다. 파서는 완료된 바이트 프레임을 순서대로 반환하고 화면 버퍼가 최신 한 장을 선택합니다. 운동 이벤트는 이 파서와 별도 경로입니다.
