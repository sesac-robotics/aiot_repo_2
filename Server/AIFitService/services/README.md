# 서비스 로직

이 폴더는 API 요청 처리와 데이터 접근을 조합해 AIFit의 핵심 기능을 수행합니다. 라우터는 HTTP 요청과 응답을 담당하고, 서비스는 인증·체형 분석에 필요한 실제 처리 흐름을 맡습니다.

## 서비스 구성

| 파일 | 역할 |
|---|---|
| `auth_service.py` | 비밀번호 해시 생성·검증, 회원가입 처리, 로그인 검증 및 JWT 발급 |
| `token_service.py` | Bearer JWT의 서명과 만료를 확인하고 요청 사용자를 조회 |
| `body_analysis_service.py` | 업로드된 사진을 OpenAI API로 보내 체형 상태를 분석하고 7일 운동 루틴을 구조화된 형식으로 생성 |
| `exercise_names.py` | 한글 운동명과 표시명을 AI Server가 사용하는 표준 운동 식별자로 변환 |

## 기능 흐름

1. 인증 라우터가 요청 모델을 인증 서비스에 전달합니다. 비밀번호는 PBKDF2 해시로 저장하며, 로그인 성공 시 JWT를 발급합니다.
2. 보호된 API는 토큰 서비스를 통해 요청자의 토큰과 계정 상태를 확인합니다.
3. 체형 분석 라우터는 사진 분석 서비스의 결과를 검증하고, 운동 루틴을 데이터베이스에 연결합니다.
4. 운동명 정규화 기능은 체형 분석 결과와 운동 세션이 같은 운동 식별자를 사용하도록 맞춥니다.

## 외부 연동

사진 분석에는 `OPENAI_API_KEY`와 `OPENAI_MODEL` 설정이 필요합니다. 분석 지침과 응답 스키마를 사용해 결과를 JSON 구조로 받고, 서버에서 허용된 상태값과 7일 루틴 규칙을 다시 검증합니다. 비밀번호 원문이나 JWT 비밀 키는 응답에 포함하지 않습니다.
