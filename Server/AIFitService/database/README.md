# 데이터베이스 연결

이 폴더는 AIFit Server 전반에서 사용하는 SQLite 연결과 기본 사용자 테이블 초기화를 담당합니다.

## `connection.py`

- `get_connection()` — 설정된 SQLite 파일에 연결하고, 컬럼명으로 결과를 조회할 수 있게 하며, 외래 키 검사를 연결마다 활성화합니다.
- `init_db()` — `UserInfo` 테이블이 없을 때 생성합니다.

## 스키마와 마이그레이션

사용자 외의 기본 테이블 스키마는 `AIFitDB/AIFit.sql`에서 관리합니다. 기능별 라우터는 필요한 테이블이나 기존 DB의 추가 컬럼을 서버 시작 시 생성·마이그레이션합니다. 예를 들어 운동 세션 라우터는 기존 기록을 보존하면서 세션 진행 상태와 heartbeat 시각을 관리하는 구조를 준비합니다.

## 데이터 경로와 관리

DB 파일 경로는 `config/settings.py`에서 정하며 `AIFIT_DB_PATH` 환경 변수로 바꿀 수 있습니다. SQLite DB와 백업에는 개발·사용자 기록이 들어갈 수 있으므로 저장소에는 SQL 스키마와 문서를 공유하고 실제 데이터 파일은 포함하지 않는 방식으로 관리합니다.
