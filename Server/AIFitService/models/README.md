# API 요청 모델

이 폴더는 API 요청에서 사용하는 데이터 구조와 입력값 검증 규칙을 정의합니다. 라우터가 비즈니스 로직을 실행하기 전에 잘못된 형식이나 범위를 가진 입력을 걸러냅니다.

## `auth_models.py`

계정 및 프로필 API에서 사용하는 요청 모델을 제공합니다.

- **회원가입:** 아이디, 비밀번호, 이메일, 닉네임, 성별, 나이, 키, 몸무게
- **로그인:** 아이디와 비밀번호
- **프로필 수정:** 이메일과 기본 프로필 정보
- **비밀번호 변경:** 새 비밀번호 확인값이 일치하는지, 현재 비밀번호와 다른지 검증
- **계정 삭제:** 본인 확인을 위한 비밀번호

Pydantic 검증을 사용해 이메일 형식, 문자열 길이, 성별 허용값, 숫자 범위를 확인합니다. 요청 모델과 라우터의 입력 형식을 명확히 분리해 API 데이터 계약을 관리합니다.

## 요청 처리 흐름

`routers/`의 엔드포인트가 요청 모델을 입력으로 받으면 FastAPI와 Pydantic이 먼저 유효성을 검사합니다. 검증에 실패하면 요청 처리 로직에 도달하기 전에 오류 응답을 반환합니다.
