# 데이터 저장소 계층

이 폴더는 애플리케이션 서비스와 SQLite 사이의 데이터 접근을 담당합니다. 사용자 조회·저장·수정 SQL을 저장소 함수로 모아 라우터와 서비스가 데이터베이스 세부 구현에 직접 얽히지 않도록 했습니다.

## `user_repository.py`

사용자 데이터에 대해 다음 작업을 제공합니다.

- 아이디 또는 사용자 ID로 계정 조회
- 아이디 및 이메일 중복 확인(이메일은 대소문자를 구분하지 않음)
- 회원 생성과 프로필 정보 수정
- 비밀번호 해시 조회 및 갱신
- 계정과 연결된 체형 분석, 운동 세션, 반복 기록, 리포트 삭제

계정을 삭제할 때 다른 사용자나 세션이 참조하는 운동 루틴은 유지합니다. 사용자 입력값은 SQL 매개변수로 전달해 쿼리와 데이터를 분리합니다.

## 데이터 접근 흐름

인증·프로필 서비스가 저장소 함수를 호출하고, 저장소는 `database/connection.py`를 통해 연결을 얻습니다. 이를 통해 사용자 데이터 접근 방식을 일관되게 유지합니다.
