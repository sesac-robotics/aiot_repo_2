# VS Code에서 데이터셋 테스트하기

**영상과 교정 문구를 바로 보려면 상위 폴더의 `run_demo.py`를 열고 오른쪽 위 ▶ 실행 버튼을 누르세요.** 브라우저가 자동으로 열리며, 데스크톱 화면에서 영상 왼쪽 / 교정 문구 오른쪽으로 나옵니다. 영상은 무음으로 자동 재생됩니다. 포트가 사용 중이면 비어 있는 포트를 자동 선택합니다. `test_server.py`는 검사 코드이므로 데모 실행 파일이 아닙니다.

추가 패키지 설치 없이 Python 3 표준 라이브러리로 실행합니다.

```bash
code /home/yoo/R2D2/shoulder-qevd/shoulder-qevd.code-workspace
python3 /home/yoo/R2D2/shoulder-qevd/test_app/server.py
```

브라우저에서 **http://127.0.0.1:8765** 를 엽니다. 서버는 이 컴퓨터의 localhost에서만 열립니다. 종료하려면 실행 터미널에서 Ctrl+C를 누르세요.

VS Code에서는 `터미널 → 작업 실행 → 테스트 화면 실행`으로도 실행할 수 있습니다. Python Debugger 확장이 있다면 F5로 중단점을 사용해 실행할 수 있습니다. 이미 서버가 켜져 있으면 그 화면을 사용하거나 기존 서버를 종료하고 다시 실행하세요. 다른 포트는 `--port 8766`으로 지정할 수 있습니다.

## 확인할 내용

1. 기본 선택은 어깨 데이터셋 100개 초안입니다. 영상 재생과 이동이 가능한지 확인합니다.
2. 검색에 `subject_023`을 넣고 `상세 비교 사례만`을 선택하면 좌우 높이·타이밍 불균형 사례를 볼 수 있습니다. 아래 good/bad 영상과 비교 이미지도 확인하세요.
3. 라벨에서 `forearms tilt inward`를 선택하면 전완이 안쪽으로 기울어지는 후보 10개가 표시됩니다.
4. 자료를 `QEVD`로 바꾸고 스쿼트·푸시업·엘보 플랭크·YTW를 선택해 기존 라벨 형식과 비교할 수 있습니다. YTW를 포함한 QEVD 63개 라벨 모두에 별도로 작성한 영어 피드백 템플릿이 연결되어 있습니다. 이 문구는 초안이며 원본 자유형 피드백은 보존됩니다. 상단 종목 버튼으로 바로 전환할 수 있습니다.
5. `데이터 검증 실행`으로 원본 해시, JSON 필드, ID 충돌, 참여자 분할을 검증합니다.

**이 화면은 저장된 라벨·피드백 연결을 확인하는 도구입니다.** 영상을 분석해 자세 오류를 새로 예측하는 AI 모델이나 실시간 카메라 판별은 아직 구현하지 않았습니다. 어깨 라벨은 모두 검수 전 초안이고, QEVD 피드백은 원본 그대로 표시하며 특정 오류와 일대일 대응이 아닐 수 있습니다.

## 파일

- `server.py`: 데이터셋 읽기, 검색·종목 필터 API, 영상 Range 스트리밍, 고정 검증 명령 실행
- `web/index.html`: 화면 구조
- `web/app.js`: 목록·영상·피드백·비교 자료 표시
- `web/styles.css`: 화면 스타일
- `test_server.py`: 검색·분할·피드백 연결·영상 이동·경로 처리 테스트

데이터셋 파일은 브라우저에서 수정하지 않습니다. 검증 버튼만 기존 `checks/validation_report.json`을 갱신합니다.
