판정: **자료 형식 병합과 라벨 인코딩은 가능하지만, 현재 코드·라벨 상태 그대로 신뢰할 수 있는 5종목 오류 학습·평가를 진행할 준비는 안 됨.**

모델 학습이나 MediaPipe 추출은 실행하지 않았습니다. 원본 라벨·분할도 변경하지 않았습니다.

## 실제 점검 수치

- 전체 18,752개: QEVD 18,652 + 어깨 초안 100개. train 17,769 / test 983개.

- 18,752개 모두 경로 확인 및 70차원 multi-hot 라벨 인코딩 dry-run 통과. 영상·참여자 ID 충돌 0개.
- 각 자료의 train/test 참여자 겹침 0개. 서로 다른 자료의 동일 인물 여부는 확인한 것이 아님.
- 어깨는 전체의 0.533%이며, 검수 완료 및 training_ready 레코드는 0개.

## 필요한 변경

1. 어깨 초안 검수: 특히 팔꿈치 간격은 그립·운동 변형인지, 머리 뒤 손 이동은 다른 운동인지 확인. 부족한 오류 유형을 추가 수집.
2. 공통 입력 생성: 두 자료 모두 같은 포즈 추출기·관절 순서·좌표 정규화·가시성 처리·시간 단위로 변환. 속도/순서 오류에는 실제 타임스탬프를 보존.
3. 라벨 의미 정의: 정상·동작 특성·오류·판독 불가를 구분. 미검토 항목은 음성 정답으로 강제하지 않고 불확실성 마스크/가중치로 관리.
4. 모델 출력 변경: 5종목 분류와 종목별 복수 오류 예측을 구분. 운동별 오류 기준을 유지하고 피드백 문구는 예측 코드에서 매핑.
5. 분할 재설계: QEVD 공식 test 유지. 어깨는 검수·추가 수집 후 사람 기준 분할과 유형별 지원 수를 확인. 검증용 데이터는 학습 참여자에서 별도 분리.
6. 불균형 처리: 학습 데이터에서 종목·오류별 샘플링/가중치를 결정. test/validation은 학습에 넣지 않음. 증강과 다른 시점 사본을 새로운 참여자로 세지 않음.
7. 성능 확인: 전체 정확도 하나 대신 운동별·오류별 precision/recall/F1 및 독립 ESP32-CAM 영상으로 측정. 드문 클래스는 평가 불가로 표시.

## 현재 권장 범위

검수 전 초안을 명시한 학습 파이프라인 실험은 가능합니다. 실시간 교정 정확도를 주장하거나 최종 평가에 사용하기에는 어깨 라벨과 테스트 지원이 부족합니다. 데이터 형식이 같다는 사실이 정답 라벨과 모델의 호환성을 보장하지는 않습니다.
